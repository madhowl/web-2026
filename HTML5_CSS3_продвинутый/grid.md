## 1. Что такое Grid и зачем он нужен

**CSS Grid** — двухмерная система раскладки. В отличие от **Flexbox**, который работает в **одну ось** (ряд ИЛИ колонка), Grid управляет одновременно **строкАми и столбцами**. Это идеально для построения общего каркаса страницы.

Представьте таблицу, в которой можно свободно «расставлять» элементы по ячейкам и растягивать их через несколько строк/столбцов — это и есть Grid.

**Сравнение с Flexbox:**

| | Flexbox | Grid |
|--|---------|------|
| Измерность | 1D (ряд или колонка) | 2D (строки и столбцы) |
| Лучше для | Выравнивания содержимого в строке | Общего каркаса и сетки |
| Ориентация | Поток контента | Раскладка по области |

> Главное правило: **Grid задаёт каркас**, **Flexbox выравнивает содержимое** внутри ячеек.

## 2. Базовый синтаксис: display grid

Чтобы включить Grid, родителю задают `display: grid`:

```html
<div class="grid">
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
    <div class="item">4</div>
</div>
```

```css
.grid {
    display: grid;
}
```

Пока Grid «не настроен», он ведёт себя как блочный контейнер. Реальная двухмерность появляется после описания колонок и строк.

## 3. grid-template-columns и grid-template-rows

Эти свойства задают размер и количество колонок / строк.

### 3.1. Колонки `grid-template-columns`

```css
.grid {
    display: grid;
    grid-template-columns: 200px 200px 200px; /* 3 колонки по 200px */
}
```

Каждое значение создаёт **одну колонку** шириной в это значение.

### 3.2. Строки `grid-template-rows`

```css
.grid {
    display: grid;
    grid-template-columns: 100px 100px;
    grid-template-rows: 100px 100px 100px; /* 3 строки по 100px */
}
```

Получается сетка 2×3 (2 колонки, 3 строки) — 6 ячеек.

## 4. Единицы fr, minmax(), repeat()

### 4.1. `fr` (fraction — доля)

`1fr` — «одна доля» свободного пространства. Гибкая и очень частая единица:

```css
.grid {
    grid-template-columns: 1fr 2fr 1fr;
    /* 4 доли всего: 1fr + 2fr + 1fr.
       2fr вдвое шире 1fr */
}
```

### 4.2. `minmax()`

Задаёт минимальное и максимальное значение:

```css
.grid {
    grid-template-columns: minmax(200px, 1fr) 300px;
    /* первая колонка: не уже 200px, но может тянуться до 1fr */
}
```

### 4.3. `repeat()`

Повторяет шаблон несколько раз:

```css
.grid {
    grid-template-columns: repeat(3, 1fr);  /* 3 равные доли */
    grid-template-columns: repeat(4, 100px); /* 4 колонки по 100px */
}
```

### 4.4. Собираем вместе

```css
.layout {
    display: grid;
    grid-template-columns: 1fr minmax(250px, 2fr) 1fr;
    /* сайдбар — основная колонка — сайдбар */
}
```

## 5. Отступы gap

`gap` задаёт расстояние между **строками и столбцами** (не снаружи контейнера!):

```css
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;          /* и между рядами, и между колонками */
    row-gap: 10px;      /* отдельно по строкам */
    column-gap: 30px;   /* отдельно по колонкам */
}
```

> ⚠️ `gap` — расстояние **между элементами**. Для отступа от краёв используйте `padding` на контейнере.

## 6. Размещение элементов по ячейкам

По умолчанию элементы «заполняют» сетку по порядку (каждый в следующую свободную ячейку). Но можно размещать их точно.

Элементам задают:

- `grid-column-start` / `grid-column-end`
- `grid-row-start` / `grid-row-end`
- или сокращённо `grid-column` / `grid-row`

Значения считаются **по линиям** сетки (линий на 1 больше, чем колонок/строк):

```
   [1]     [2]     [3]     [4]
  ┌──────┬──────┬──────┐
[1]      │      │      │
  ├──────┼──────┼──────┤
[2]      │      │      │
  └──────┴──────┴──────┘
```

Пример — элемент занимает крайнюю левую колонку на всю высоту:

```css
.sidebar {
    grid-column: 1 / 2;  /* от линии 1 до линии 2 (1 колонка) */
    grid-row: 1 / 3;      /* от линии 1 до линии 3 (2 строки) */
}
```

Сокращённо через `grid-area` — `строка_начала / колонка_начала / строка_конца / колонка_конца`:

```css
.sidebar {
    grid-area: 1 / 1 / 3 / 2;
}
```

### 6.1. `span` — «растянуться на N»

```css
.featured {
    grid-column: span 2; /* занять 2 колонки */
}
```

## 7. Шаблонные области grid-template-areas

Самый наглядный способ описать макет — «рисовать» его словами через `grid-template-areas`.

```css
.page {
    display: grid;
    grid-template-columns: 1fr 3fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header header"
        "nav    main"
        "footer footer";
    gap: 10px;
}
```

Каждая строка в кавычках — одна **строка сетки**, каждое имя — **ячейка**. Одинаковые имена в соседних ячейках объединяются в одну область (здесь «header» занимает обе колонки).

Элементы связываются с областями через `grid-area`:

```css
.page-header { grid-area: header; }
.page-nav    { grid-area: nav; }
.page-main   { grid-area: main; }
.page-footer { grid-area: footer; }
```

```html
<div class="page">
    <header class="page-header">Логотип</header>
    <nav class="page-nav">Меню</nav>
    <main class="page-main">Контент</main>
    <footer class="page-footer">Подвал</footer>
</div>
```

### 7.1. Правила grid-template-areas

- Области должны образовывать **прямоугольники** (нельзя L-образные фигуры).
- Пустая ячейка — точка `.`.
- Одинаковые имена создают одну прямоугольную область.

## 8. Выравнивание в Grid

`justify-items` / `align-items` на контейнере управляют ячейками:

- `justify-items` — по горизонтали (start, end, center, stretch).
- `align-items` — по вертикали.

На элементе индивидуально: `justify-self` / `align-self`.

У самого контейнера можно задать выравнивание всей сетки внутри него: `justify-content` / `align-content` (нужно, когда сетка меньше контейнера — например, колонки `px`).

```css
.center-item {
    justify-self: center; /* отцентрировать элемент в своей ячейке */
    align-self: center;
}
```

## 9. Практика: каркас сайта

Соберём классический каркас страницы на Grid с семантическими тегами:

```css
* { box-sizing: border-box; }
body { margin: 0; font-family: Arial, sans-serif; }

.page {
    display: grid;
    grid-template-columns: 1fr 3fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header header"
        "sidebar content"
        "footer footer";
    min-height: 100vh;
    gap: 10px;
}

.page header { grid-area: header; background: #333; color: #fff; padding: 10px; }
.page aside  { grid-area: sidebar; background: #eee; padding: 10px; }
.page main   { grid-area: content; background: #fafafa; padding: 10px; }
.page footer { grid-area: footer; background: #333; color: #fff; padding: 10px; }
```

```html
<div class="page">
    <header>Шапка сайта</header>
    <aside>Сайдбар</aside>
    <main>Основной контент</main>
    <footer>© 2026</footer>
</div>
```

Результат: шапка на всю ширину сверху, под ней сайдбар слева и контент справа, снизу подвал.

## 10. Практика: адаптивная галерея

Автоматически подстраивающаяся сетка карточек — одна из любимых задач Grid.

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 15px;
}

.card {
    background: #e8e8e8;
    padding: 20px;
    border-radius: 8px;
}
```

**Разбор:** `repeat(auto-fit, minmax(200px, 1fr))` — сетка сама решает, сколько колонок влезет: чем шире экран, тем больше колонок по ~200px; если тесно — переносит на новую строку. **Автоадаптив без единого медиа-запроса!**

- `auto-fit` — колонки растягиваются, заполняя всю ширину.
- `auto-fill` — колонки сохраняют размер, свободное место остаётся пустым.

## 11. Практика: разбор типичных ошибок

### Сломанный Grid:

```css
.grid {
    display: grid;
    grid-template: none;        /* ← ошибка синтаксиса (нет такого краткого значения в этом виде) */
    gap: 20px;
}
.item:first-child {
    grid-column: 2 / 4;         /* может выйти за сетку, если колонок меньше */
}
```

### Разбор:

| Ошибка | Пояснение / исправление |
|--------|--------------------------|
| `grid-template: none` | Или задавайте `grid-template-columns/rows`, или корректный сокращённый синтаксис `grid-template: "h h" "m s" / 1fr 3fr` |
| Элемент по колонкам за пределами сетки | Элемент может «выдвинуться» за пределы. Задайте сетке достаточно колонок или используйте `span` |
| Забыт `display: grid` у родителя | `grid-column`, `gap` и пр. работают только внутри grid-контейнера |
| Путаница `auto-fit` и `auto-fill` | `auto-fit` растягивает колонки по ширине, `auto-fill` оставляет пустые места |
| `gap` считают наружным отступом | `gap` — только между ячейками; наружные отступы делает `padding` |

### Дополнительные частые ошибки:

1. **Незаданные строки.** Если `grid-template-rows` не задан, строки создаются автоматически по содержимому — высота может отличаться.
2. **Области не прямоугольные.** `grid-template-areas` не позволяет L- или T-образные области.
3. **Смешение линии и `span`.** `grid-column: 1 / span 2` — корректно (с 1-й, на 2 колонки). Но следите за направлением.
4. **Забыли, что `1fr` не меньше содержимого.** Минимум колонки определяет содержимое; чтобы ограничить, используйте `minmax(0, 1fr)`.

```css
.overflow-free {
    grid-template-columns: minmax(0, 1fr) 300px; /* защита от переполнения */
}
```

## 12. Упражнения и итоговый контроль

### Упражнения

1. **Три колонки.** Сетка `1fr 2fr 1fr` из 6 элементов, `gap: 20px`.
2. **Строки и колонки.** Сетка 3×3 с размерами через `minmax` и `repeat`.
3. **Шапка-подвал.** Каркас с `grid-template-areas`: header, sidebar, content, footer (как в разделе 9).
4. **Растянутая карточка.** В галерее одна карточка занимает 2 колонки (`grid-column: span 2`).
5. **Автоадаптив.** Галерея с `auto-fit minmax(150px, 1fr)`; проверьте при изменении ширины окна.

### Вопросы для самопроверки

1. Чем Grid отличается от Flexbox?
2. Что значит `1fr`? Сколько колонок в `repeat(4, 1fr)`?
3. Что делает `minmax(200px, 1fr)`?
4. Разница `auto-fit` и `auto-fill`?
5. Как растянуть элемент на 2 строки?
6. Зачем `grid-template-areas`?
7. Почему иногда пишут `minmax(0, 1fr)`?

### Ошибки, которые важно запомнить

> - Grid — это **контейнер** и **элементы**: свойства сетки на родителе, размещения — на детях.
> - `gap` между элементами, `padding` — наружу.
> - Проверяйте факт `display: grid`, иначе дочерние `grid-*` не сработают.
