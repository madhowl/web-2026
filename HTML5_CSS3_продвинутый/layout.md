## 1. Flexbox или Grid: как выбирать

Два мощных инструмента. Практическое правило выбора:

> **Flexbox** — когда элемент должен «течь» в одной линии и выравниваться по ней.
> **Grid** — когда нужно управлять **сеткой** из строк и колонок одновременно.

### Типичные сценарии

| Задача | Инструмент |
|--------|-----------|
| Горизонтальное меню | Flexbox |
| Вертикальная колонка кнопок | Flexbox (column) |
| Центрирование | Flexbox |
| Каркас страницы (шапка/сайдбар/подвал) | Grid |
| Галерея карточек | Grid |
| Карточка с «прижатым» низом | Flexbox (в колонке) |
| Сложный модульный макет | Grid |

### Гибридный подход (самый распространённый)

Внутри ячеек **Grid** часто применяют **Flexbox** для выравнивания содержимого. Это стандартная связка.

```css
.page {
    display: grid;
    grid-template-columns: 1fr 2fr;
}

.card {
    display: flex;
    flex-direction: column;   /* элементы карточки в столбик */
}
.card .footer {
    margin-top: auto;          /* «прижать» футер карточки к низу */
}
```

`margin-top: auto` внутри flex-колонки — удобный трюк, чтобы **прижать элемент к низу**.

## 2. auto-fit / auto-fill в деталях

Как было в [Разделе 1](grid.md#10-практика-адаптивная-галерея), `repeat(auto-fit, minmax(...))` создаёт автоадаптивную сетку. Уточним разницу.

```css
.auto-fit { grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)); }
.auto-fill { grid-template-columns: repeat(auto-fill, minmax(150px, 1fr)); }
```

- **`auto-fit`**: пустые «лишние» колонки схлопываются, оставшиеся **растягиваются** на всю ширину. Элементы занимают всё доступное место.
- **`auto-fill`**: колонки создаются под нужную ширину, но при свободном месте остаются **пустые треки** (элементы не растягиваются).

На практике, когда карточек мало, `auto-fit` обычно выглядит лучше (нет «дыр» справа).

**Ограничение:** `auto-fit`/`auto-fill` будут работать как надо для однородных элементов. Если элементы разной ширины — поведение может удивить.

## 3. Единицы измерения в CSS

Выбор единицы влияет на адаптивность и предсказуемость вёрстки.

### Абсолютные

| Единица | Описание |
|---------|----------|
| `px` | Пиксели. Точные, фиксированные. Удобны для рамок, отступов, фикс. размеров. НЕ масштабируются |

### Относительные (от шрифта)

| Единица | Описание |
|---------|----------|
| `em` | Относительно **родителя**. 1em = размер шрифта родителя. Может «накапливаться» во вложенности |
| `rem` | Относительно **корня** `<html>`. Предсказуемый, единый масштаб. Рекомендуется для шрифтов |

### Относительные (от вьюпорта)

| Единица | Описание |
|---------|----------|
| `vw` | 1% ширины окна |
| `vh` | 1% высоты окна |
| `vmin` | Меньшее из vw/vh |
| `vmax` | Большее из vw/vh |

Пример:

```css
html { font-size: 16px; }
h1 { font-size: 2rem; }        /* 32px, независимо от родителей */
.hero { height: 100vh; }       /* экран на всю высоту окна */
.text { width: 50vw; }         /* половина ширины окна */
```

### Проценты `%`

Относительны **родителя** по соответствующей оси (ширина от ширины родителя, высота от высоты при заданной высоте родителя).

```css
.child { width: 50%; }  /* половина ширины родителя */
```

> ⚠️ **Проценты высоты** работают, только если у родителя задана высота. Иначе высота останется по содержимому.

### `clamp()` — «резиновый» размер

`clamp(мин, предпочтительный, макс)` — идеально для адаптивной типографики:

```css
h1 {
    font-size: clamp(1.5rem, 4vw + 1rem, 3rem);
    /* от 1.5rem до 3rem, но стремится к 4vw+1rem */
}
```

Размер плавно растёт с шириной экрана, но не выходит за пределы.

## 4. CSS-переменные (Custom Properties)

CSS-переменные позволяют хранить значения и переиспользовать их. Объявляются в любом правиле, обычно в `:root` (для глобальной видимости).

### 4.1. Объявление и использование

```css
:root {
    --main-color: #3498db;
    --main-padding: 16px;
    --border-radius: 8px;
}

.button {
    background: var(--main-color);
    padding: var(--main-padding);
    border-radius: var(--border-radius);
}
```

- Объявление: `--имя: значение;` (двойной дефис перед именем).
- Использование: `var(--имя)`.

### 4.2. Значения по умолчанию

```css
.button {
    background: var(--main-color, #888);
    /* если --main-color не задан — используется #888 */
}
```

### 4.3. Переопределение (уже на уровне блока)

Переменные **наследуются** и **каскадируются** — их можно переопределить локально:

```css
.dark-theme {
    --main-color: #2c3e50;
}
/* Все --main-color внутри .dark-theme станут тёмными */
```

Это основа тем оформления (светлая/тёмная тема):

```css
:root { --bg: #fff; --text: #222; }
@media (prefers-color-scheme: dark) {
    :root { --bg: #222; --text: #eee; }
}
body { background: var(--bg); color: var(--text); }
```

### 4.4. Почему это удобно

- Меняете тему в одном месте — меняется везде.
- Читаемые имена вместо «магических» значений.
- Позволяют менять значения в DevTools сразу на всей странице.
- Работают в `transition` и `animation`.

## 5. Типовые каркасы: комбинация Grid и Flexbox

### 5.1. Каркас с шапкой, сайдбаром, контентом и подвалом

```css
.layout {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header header"
        "aside  main"
        "footer footer";
    min-height: 100vh;
}
```

### 5.2. Двухколоночный контент, где колонки выравнивают низ через Flexbox

```css
.section {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 20px;
}
.card {
    display: flex;
    flex-direction: column;
    border: 1px solid #ddd;
    padding: 20px;
}
.card .card-action {
    margin-top: auto;   /* кнопка всегда внизу карточки */
}
```

### 5.3. Шапка: Flexbox для меню

```css
.topbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 0 20px;
}
.nav {
    display: flex;
    gap: 20px;
}
```

## 6. Практика: разбор типичных ошибок

| Ошибка | Исправление |
|--------|-------------|
| Используют Grid для простого ряда кнопок | Хватит Flexbox |
| `margin-top: auto` не «прижимает» элемент | Проверьте, что родитель — flex с `flex-direction: column` и задана высота |
| `rem` применяют к рамкам/отступам, страдая от масштабирования | Для геометрии (рамок, части отступов) чаще подходит `px` |
| `em` во вложенности «убегает» (эффект снежного кома) | Для предсказуемости используйте `rem` на шрифтах |
| `%` высоты не работает | Родителю нужна заданная высота |
| Переменная объявлена внутри элемента, а используется на всём сайте | Объявляйте глобальные переменные в `:root` |
| Опечатка `--имя` / `var(--имя)` | Имя должно быть одинаковым, включая двойной дефис |
| `vmin/vmax` путают | `vmin` — меньшее, `vmax` — большее из vw/vh |

## 7. Упражнения

1. Создайте каркас Grid (header/nav/main/footer) и внутри `<main>` расположите блоки через Flexbox.
2. Сделайте галерею `repeat(auto-fit, minmax(180px, 1fr))` — проверьте auto-fit vs auto-fill.
3. Определите `--main-color`, `--spacing`, `--radius` в `:root` и используйте их в стилях.
4. Попробуйте `clamp()` для заголовка: сделайте, чтобы размер плавно менялся 2–4rem.
5. Реализуйте переключение тёмной/светлой темы через переменные и `@media (prefers-color-scheme)`.
