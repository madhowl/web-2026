## 📗 Начальный уровень — `HTML5_CSS3_учебник/`

Для тех, кто начинает с нуля.

- **`index.md`** — оглавление и порядок чтения
- **`html.md`** — часть 1: HTML5
- **`css.md`** — часть 2: CSS3

### Что внутри (HTML5)
- Структура документа, текст, списки, ссылки, таблицы
- Блочные и строчные элементы
- Формы, семантическая разметка
- Мультимедиа (audio/video), мета-теги
- Разбор типичных ошибок + упражнения

### Что внутри (CSS3)
- Селекторы, цвета, типографика, блочная модель
- Display и позиционирование
- Flexbox
- CSS3: градиенты, тени, переходы, анимации, адаптивность
- Разбор типичных ошибок + упражнения

## 📙 Продвинутый уровень — `HTML5_CSS3_продвинутый/`

Следующий шаг после основ. Требуется знание базового курса.

- **`index.md`** — оглавление и рекомендуемый порядок чтения
- **`grid.md`** — раздел 1: CSS Grid
- **`layout.md`** — раздел 2: Flexbox + Grid, единицы измерения, CSS-переменные
- **`styling.md`** — разделы 3–4: оформление форм, продвинутая типографика
- **`animation.md`** — разделы 5–6: трансформации, переходы, анимации
- **`responsive.md`** — разделы 7–8: адаптивность, доступность (a11y)
- **`workflow.md`** — разделы 9–11: BEM, препроцессоры, инструменты
- **`project.md`** — разделы 12–13: продвинутые селекторы, итоговый проект

### Освещаемые темы
- CSS Grid, auto-fit / auto-fill
- Единицы измерения, CSS-переменные
- Кастомные формы, веб-шрифты, clamp()
- Анимации на @keyframes, prefers-reduced-motion
- Мобильный-first, доступность, ARIA
- Методология BEM, Sass/SCSS
- Продвинутые селекторы (:not, :is, :where, :has)
- Итоговый проект: адаптивный лендинг студии веб-дизайна

## Как пользоваться

1. Создайте текстовые файлы из примеров (`.html`, `.css`).
2. Открывайте `.html` в браузере и проверяйте результат.
3. Выполняйте упражнения вручную и сверяйтесь с материалом.
4. Рекомендуемый редактор — VS Code с расширением для предпросмотра Markdown.

> 💡 Начните с [`HTML5_CSS3_учебник/index.md`](HTML5_CSS3_учебник/index.md), затем переходите к продвинутому.
