## 🌐 Сетевые протоколы — `Сетевые_протоколы/`

Как работает интернет: от адресации до безопасной передачи данных. Для веб-разработчиков и всех, кому важна сетевая «изнанка».

- **`index.md`** — оглавление и рекомендуемый порядок чтения
- **`networking.md`** — разделы 1–2: введение, модели OSI и TCP/IP
- **`tcp-ip.md`** — разделы 3–6: IP-адресация, TCP (рукопожатие), UDP, порты
- **`dns.md`** — разделы 7–8: DNS, типы записей, запросы, кэширование, DoH/DoT
- **`http.md`** — разделы 9–10: HTTP, методы, статус-коды, заголовки, HTTP/2/3
- **`https.md`** — разделы 11–12: cookies, сессии, кэширование, CORS, TLS/HTTPS
- **`practice.md`** — раздел 13: практика, диагностика, итоговая самопроверка

### Освещаемые темы
- Модель OSI (7 уровней) и TCP/IP (4 уровня)
- IPv4/IPv6, приватные адреса, NAT, порты и сокеты
- TCP: трёхстороннее рукопожатие, надёжность; UDP: скорость
- DNS: иерархия, записи (A, AAAA, CNAME, MX, TXT), TTL, dig/nslookup
- HTTP: методы, статус-коды, заголовки, эволюция HTTP/1.1 → HTTP/3
- Cookies, сессии, JWT, кэширование (ETag), CORS
- HTTPS/TLS: сертификаты, центры сертификации, рукопожатие, шифрование
- Диаграммы **Mermaid** по каждому процессу

## Как пользоваться

1. Создайте текстовые файлы из примеров (`.html`, `.css`).
2. Открывайте `.html` в браузере и проверяйте результат.
3. Выполняйте упражнения вручную и сверяйтесь с материалом.
4. Для команд из курса по сетевым протоколам используйте терминал (Linux/macOS/Windows).
5. Рекомендуемый редактор — VS Code с расширениями для предпросмотра Markdown и Mermaid.
