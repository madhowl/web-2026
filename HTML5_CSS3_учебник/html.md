## 1. Введение в HTML

### 1.1. Что такое HTML?

**HTML** (HyperText Markup Language — «язык гипертекстовой разметки») — это язык, с помощью которого создаётся **структура** веб-страниц. Он описывает, что именно находится на странице: заголовки, текст, картинки, кнопки, ссылки и так далее.

Важно понять главную мысль:

> **HTML отвечает за СТРУКТУРУ и СОДЕРЖИМОЕ страницы.**
> За ВНЕШНИЙ ВИД отвечает CSS, а за ПОВЕДЕНИЕ — JavaScript.

Представьте себе дом:
- **HTML** — это каркас, стены, комнаты и фундамент.
- **CSS** — это покраска, обои, мебель и декор.
- **JavaScript** — это электричество, водопровод и автоматика (то, что «работает»).

### 1.2. Что такое «тег»?

HTML состоит из **тегов** — специальных команд, заключённых в угловые скобки. Тег говорит браузеру, как отображать ту часть текста, которую он охватывает.

Большинство тегов — **парные**: у них есть открывающий и закрывающий тег.

```html
<p>Это абзац текста</p>
```

- `<p>` — открывающий тег (начало абзаца)
- `</p>` — закрывающий тег (конец абзаца, со слэшем `/`)

Однако есть и **одиночные (непарные) теги**, например `<img>` (изображение) или `<br>` (перевод строки). У них нет закрывающего тега.

### 1.3. Какие инструменты нужны?

Для создания HTML-страниц вам понадобится всего два инструмента:

1. **Текстовый редактор** — где вы пишете код. Рекомендую **VS Code** (бесплатный).
2. **Браузер** — Chrome, Firefox, Edge и т.д. Он выполняет ваш HTML-код.

### 1.4. Как создать первую страницу?

**Шаг 1.** Создайте файл с расширением `.html`, например `index.html`.

**Шаг 2.** Откройте его в VS Code и напишите простой текст:

```html
Привет, мир!
```

**Шаг 3.** Откройте файл в браузере (двойной клик по файлу). Вы увидите страницу с надписью «Привет, мир!».

Возможно, вам кажется, что это слишком просто и «неправильно». И вы правы — так писать страницы нельзя. В следующей главе мы изучим **правильную структуру** документа.

## 2. Структура HTML-документа

Любой корректный HTML5-документ имеет жёсткую, обязательную структуру. Она выглядит так:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Добро пожаловать!</h1>
    <p>Это моя первая HTML-страница.</p>
</body>
</html>
```

Разберём каждый элемент:

### 2.1. `<!DOCTYPE html>`

Эта строка **обязательна** и всегда стоит первой. Она сообщает браузеру, что документ написан по стандарту HTML5. Без неё браузер может отобразить страницу неправильно.

### 2.2. `<html lang="ru">`

Корневой элемент всей страницы. Внутри него находится всё остальное.

- Атрибут `lang="ru"` указывает язык страницы (русский). Это важно для поисковиков и для озвучки страницы программами для слабовидящих.

### 2.3. `<head>`

«Голова» документа. Здесь находится **служебная информация**, которая НЕ отображается на странице: кодировка, заголовок вкладки, описания, ссылки на стили.

Внутри `<head>` обычно находятся:

- `<meta charset="UTF-8">` — кодировка, чтобы правильно отображались русские буквы.
- `<meta name="viewport" ...>` — настройки отображения на мобильных устройствах.
- `<title>...</title>` — название страницы, которое видно **во вкладке браузера**.

### 2.4. `<body>`

«Тело» документа. Всё, что находится внутри `<body>`, будет **видно на странице** посетителю.

### 2.5. Отступы между тегами

Обратите внимание на отступы в примере выше — теги, вложенные внутрь других, сдвинуты вправо. Это **не обязательно** для работы, но делает код читаемым. Ведите отступы всегда — это признак профессионализма.

## 3. Текст: заголовки и параграфы

### 3.1. Заголовки `<h1>`–`<h6>`

Заголовки структурируют текст по важности. Их шесть уровней, от самого важного `<h1>` до самого мелкого `<h6>`.

```html
<h1>Это заголовок первого уровня</h1>
<h2>Заголовок второго уровня</h2>
<h3>Заголовок третьего уровня</h3>
<h4>Заголовок четвёртого уровня</h4>
<h5>Заголовок пятого уровня</h5>
<h6>Заголовок шестого уровня</h6>
```

**Важные правила:**

- На странице должен быть **только один** `<h1>` — самый главный заголовок (обычно название страницы).
- Нельзя «перепрыгивать» уровни просто ради размера (например, сразу h1 → h4). Уровни должны идти по порядку.
- `<h1>` автоматически отображается крупным, `<h6>` — мелким. Но размером занимается CSS, а не HTML.

### 3.2. Абзацы `<p>`

Абзац — блок текста. Браузер автоматически добавляет отступы между абзацами.

```html
<p>Это первый абзац. В нём несколько слов.</p>
<p>Это второй абзац. Браузер поставит между ними расстояние.</p>
```

### 3.3. Перенос строки `<br>` и горизонтальная линия `<hr>`

- `<br>` — принудительный перенос строки (не нужно ставить перенос в самом HTML-коде, это сделает `<p>`).
- `<hr>` — горизонтальная разделительная линия.

```html
<p>Первая строка<br>вторая строка после переноса</p>
<hr>
<p>Текст после разделительной линии</p>
```

> ⚠️ **Частая ошибка новичка:** нажимать Enter в коде, чтобы сделать перенос строки. Браузер **игнорирует** переносы внутри кода и схлопывает повторные пробелы в один. Для переноса нужно использовать `<br>` или новый параграф.

### 3.4. Выделение текста

HTML позволяет выделять значения слов:

- `<strong>` — **жирный** (важность).
- `<b>` — просто жирный (без смысла).
- `<em>` — *курсив* (акцент).
- `<i>` — просто курсив.
- `<mark>` — жёлтая подсветка (выделение).
- `<u>` — подчёркивание.
- `<del>` — ~~зачёркнутый~~ (удалённый текст).
- `<sub>` — нижний индекс (H~2~O — вода).
- `<sup>` — верхний индекс (x²).

```html
<p>
    Слово <strong>важное</strong>, слово <em>ударное</em>,
    текст <mark>выделен</mark> маркером,
    <sub>нижний</sub> и <sup>верхний</sup> индексы.
</p>
```

### 3.5. Код и цитаты

- `<code>` — код в тексте (моноширинный шрифт).
- `<pre>` — «предварительно отформатированный» текст: сохраняет все пробелы и переносы.
- `<blockquote>` — длинная цитата-блок.
- `<q>` — короткая цитата внутри строки.

```html
<blockquote>
    <p>Программирование — это искусство говорить компьютеру,
    что нужно делать, чтобы он понял, что вы хотите.</p>
</blockquote>
<p>Как говорил классик: <q>Гений — это 1% таланта и 99% труда</q>.</p>
<pre>
    Этот текст
    сохранит   все    пробелы
    и    переносы.
</pre>
```

## 4. Списки

Списки бывают **трёх** видов:

### 4.1. Маркированный (неупорядоченный) список `<ul>`

Внутри `<ul>` каждый пункт оборачивается в `<li>` (list item). Пункты отмечаются маркерами-точками.

```html
<ul>
    <li>Молоко</li>
    <li>Хлеб</li>
    <li>Яблоки</li>
</ul>
```

### 4.2. Нумерованный (упорядоченный) список `<ol>`

Пункты автоматически нумеруются. Нумерация добавляется браузером сама — вам не нужно вписывать цифры вручную.

```html
<ol>
    <li>Разогреть духовку до 180 градусов</li>
    <li>Замесить тесто</li>
    <li>Выпекать 30 минут</li>
</ol>
```

### 4.3. Список определений `<dl>`

Состоит из терминов `<dt>` и их определений `<dd>`.

```html
<dl>
    <dt>HTML</dt>
    <dd>Язык разметки для создания структуры страницы.</dd>
    <dt>CSS</dt>
    <dd>Язык стилей для оформления страницы.</dd>
</dl>
```

### 4.4. Вложенные списки

Список можно вкладывать в другой список. Например, внутри пункта маркированного списка — свой список.

```html
<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
    <li>Овощи
        <ul>
            <li>Помидоры</li>
            <li>Огурцы</li>
        </ul>
    </li>
</ul>
```

### 4.5. Атрибут `start` нумерованного списка

Позволяет начать нумерацию не с 1:

```html
<ol start="5">
    <li>Пятый пункт</li>
    <li>Шестой пункт</li>
</ol>
```

---

### ⚠️ Разбор частых ошибок

1. **Закрывающая скобка `<li>` необязательна?** Нет, в HTML5 закрывающий тег `<li>` можно опустить, но для читаемости всегда закрывайте его.
2. **Список без `li`.** Писать текст прямо внутри `<ul>` нельзя — текст должен быть внутри `<li>`.
3. **Вложение «навык» стиля:** каждый пункт должен быть отдельным `<li>`, а не все пункты в одном `<li>` через `br`.

## 5. Ссылки и изображения

### 5.1. Ссылки `<a>`

Ссылка создаётся тегом `<a>` (anchor — якорь). Обязательный атрибут — `href` (адрес перехода).

```html
<a href="https://ya.ru">Перейти на Яндекс</a>
```

Между открывающим и закрывающим тегом находится **видимый текст** ссылки — то, что видит пользователь на странице.

**Атрибуты ссылки:**

- `href` — адрес, на который ведёт ссылка (обязателен).
- `target="_blank"` — открыть ссылку в новой вкладке.
- `title` — всплывающая подсказка при наведении.

```html
<a href="https://google.com" target="_blank" title="Откроется Google">
    Google в новой вкладке
</a>
```

**Виды адресов в `href`:**

- **Абсолютный** — полный адрес: `https://ya.ru/page` (ведёт на другой сайт).
- **Относительный** — путь к файлу внутри вашего сайта: `page2.html`, `images/photo.jpg`, `../about.html`.
- **Якорь** — переход к месту на этой же странице: `#contact`.

### 5.2. Изображения `<img>`

Тег `<img>` — **одиночный** (непарный), у него нет закрывающего тега. Атрибут `src` указывает, откуда взять картинку, `alt` — альтернативный текст.

```html
<img src="photo.jpg" alt="Фотография кота">
```

**Почему `alt` так важен:**
1. Если картинка не загрузится, вместо неё покажется текст из `alt`.
2. Его читают **поисковики** и **программы для слабовидящих**.
3. Не указывая `alt`, вы делаете сайт менее доступным.

Браузер показывает изображение в **естественном размере** файла. Практичный способ ограничить размер — использовать атрибуты `width` и `height`:

```html
<img src="photo.jpg" alt="Кот" width="300" height="200">
```

### 5.3. Изображение как ссылка

Оберните `<img>` в тег `<a>`:

```html
<a href="https://ya.ru">
    <img src="logo.png" alt="Логотип Яндекса">
</a>
```

### 5.4. Карта изображения и `<figure>`

Для подписи к картинке удобно использовать пару `<figure>` / `<figcaption>`:

```html
<figure>
    <img src="cat.jpg" alt="Кот в шляпе">
    <figcaption>Наш кот в новой шляпе</figcaption>
</figure>
```

---

### ⚠️ Разбор частых ошибок

1. **Забыли закрыть `<img>`.** У `<img>` НЕТ закрывающего тега, но в HTML5 не нужно ставить и `<img />`. Пишите просто `<img src="..." alt="...">`.
2. **Неправильный путь к картинке.** Если файла по пути `src` нет, браузер покажет «сломанную» иконку. Проверяйте, что файл существует и путь написан верно (учитывайте регистр букв в имени файла!).
3. **Забыли `alt`.** Всегда добавляйте описание.
4. **Текстовый url в `href` без `http`.** Писать `<a href="ya.ru">` неверно — браузер воспримет «ya.ru» как путь внутри сайта. Нужно `https://ya.ru`.

## 6. Таблицы

Таблицы строятся из строк и ячеек. Основные теги:

- `<table>` — сама таблица.
- `<tr>` — строка (table row).
- `<th>` — ячейка-заголовок (table header).
- `<td>` — обычная ячейка (table data).
- `<caption>` — подпись таблицы.
- `<thead>` — «шапка» таблицы (группа строк-заголовков).
- `<tbody>` — основное тело таблицы.
- `<tfoot>` — «подвал» таблицы.

```html
<table border="1">
    <caption>Расписание занятий</caption>
    <thead>
        <tr>
            <th>День</th>
            <th>Время</th>
            <th>Предмет</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Понедельник</td>
            <td>10:00</td>
            <td>Математика</td>
        </tr>
        <tr>
            <td>Среда</td>
            <td>11:00</td>
            <td>Физика</td>
        </tr>
    </tbody>
</table>
```

### 6.1. Объединение ячеек

- `colspan="2"` — растянуть ячейку на 2 столбца.
- `rowspan="2"` — растянуть ячейку на 2 строки.

```html
<table border="1">
    <tr>
        <th>Имя</th>
        <th colspan="2">Контакт</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>phone: 123</td>
        <td>email: ivan@mail.ru</td>
    </tr>
</table>
```

> ⚠️ Атрибут `border="1"` в примерах — устаревший способ показать границы. В настоящих проектах рамками управляет CSS. Здесь он приведён только для наглядности.

---

### ⚠️ Разбор частых ошибок

1. **Путаница `th` и `td`.** Заголовок колонки — `th`, обычная ячейка — `td`.
2. **Неверное число ячеек в строке.** Все строки таблицы должны иметь одинаковое число ячеек (с учётом colspan/rowspan), иначе таблица «поедет».
3. **Ячейка без содержимого.** Если ячейка пустая — поставьте внутрь хотя бы `&nbsp;` (неразрывный пробел), иначе в некоторых браузерах ячейка может отображаться некорректно.

## 7. Блочные и строчные элементы

Это одна из важнейших тем для понимания вёрстки. Все HTML-элементы делятся на два больших типа.

### 7.1. Блочные элементы (block)

**Свойства блочных элементов:**

- Занимают **всю доступную ширину** строки.
- Каждый начинается с **новой строки**.
- Следующий блочный элемент встаёт под ним.

Примеры блочных: `<div>`, `<p>`, `<h1>`-`<h6>`, `<ul>`, `<table>`, `<section>`, `<header>`, `<footer>`.

```html
<div>Первый блок</div>
<div>Второй блок (встанет на новую строку)</div>
```

Результат: два блока друг под другом, каждый на всю ширину.

### 7.2. Строчные элементы (inline)

**Свойства строчных элементов:**

- Занимают ровно столько ширины, сколько нужно их содержимому.
- **Не переносятся** на новую строку.
- Размещаются в одну линию друг за другом.

Примеры строчных: `<a>`, `<span>`, `<strong>`, `<em>`, `<img>`, `<code>`.

```html
<p>
    Текст со <span style="color:red">строчным</span>
    элементом продолжается в строке.
</p>
```

Результат: слово «строчным» окажется в той же строке, но красным.

### 7.3. Для чего нужны `<div>` и `<span>`?

- `<div>` — **универсальный блочный** контейнер, «кирпич» для группировки блоков.
- `<span>` — **универсальный строчный** контейнер для выделения фрагмента текста.

Их используют, когда нет подходящего «осмысленного» тега. В HTML5 появилась семантика (раздел 9), чтобы реже использовать безликий `<div>`.

### 7.4. Как это влияет на реальность?

Разница блок/строка критична для вёрстки. Например, нельзя просто «поставить рядом» два блока — они встанут друг под другом. Для размещения рядом используют **Flexbox** (изучается в части CSS).

---

### ⚠️ Разбор частых ошибок

1. **Вложить блочный элемент внутрь строчного.** Например, `<a><p>...</p></a>` — так нельзя, блочный не должен находиться внутри строчного. Используйте `<a><span>...</span></a>`.
2. **Ждать, что строчные встанут «в столбик».** Строчные по определению идут в строку — это нормально.
3. **Не видите разницу, пока не добавите CSS.** На чистом HTML div и span выглядят одинаково невзрачно. Разница появляется при стилизации.

## 8. Формы в HTML5

Формы нужны, чтобы собирать данные от пользователя: ввод имени, логина, поиска, комментариев.

### 8.1. Контейнер `<form>`

Всё, что относится к одной форме, оборачивается в `<form>`.

```html
<form action="https://example.com/send" method="post">
    <!-- поля формы -->
</form>
```

Атрибуты:
- `action` — адрес, куда отправятся данные.
- `method` — способ отправки: `get` или `post`.

> Для простых учебных примеров `action` и `method` можно не указывать, но об этом нужно знать.

### 8.2. Поле ввода `<input>`

`<input>` — **одиночный** тег. Его тип задаётся атрибутом `type`.

```html
<input type="text" name="username" placeholder="Введите имя">
```

Атрибуты:
- `type` — тип поля (ниже).
- `name` — имя поля, важное для отправки данных (данные уходят как пары «имя=значение»).
- `placeholder` — серый подсказочный текст внутри поля, исчезает при вводе.
- `value` — значение по умолчанию.

**Основные типы `type`:**

| Тип | Что делает |
|-----|-----------|
| `text` | Обычное текстовое поле |
| `password` | Поле для пароля (точки) |
| `email` | Проверяет, что введён e-mail |
| `number` | Поле для чисел (со стрелками) |
| `tel` | Поле для телефона |
| `date` | Выбор даты из календаря |
| `checkbox` | Галочка (может быть отмечена) |
| `radio` | Переключатель (один из группы) |
| `file` | Выбор файла |
| `submit` | Кнопка отправки |
| `reset` | Кнопка сброса |
| `button` | Обычная кнопка |

### 8.3. Многострочный текст `<textarea>`

```html
<textarea name="comment" rows="4" cols="40">Текст по умолчанию</textarea>
```

- `rows` — высота (число строк).
- `cols` — ширина (число символов).

### 8.4. Выпадающий список `<select>`

```html
<select name="city">
    <option value="msk">Москва</option>
    <option value="spb" selected>Санкт-Петербург</option>
    <option value="kb">Казань</option>
</select>
```

- `<option>` — пункт списка; атрибут `selected` делает пункт выбранным по умолчанию.
- `value` — значение, которое отправится на сервер.

### 8.5. Подписи `<label>`

`<label>` связывает текст-подпись с полем: нажав на подпись, пользователь активирует поле. Связь создаётся через атрибут `for` и `id` у поля — они должны совпадать.

```html
<label for="name">Ваше имя:</label>
<input type="text" id="name" name="name">
```

### 8.6. Полный пример формы

```html
<form>
    <label for="login">Логин:</label>
    <input type="text" id="login" name="login"
           placeholder="Введите логин"><br><br>

    <label for="pass">Пароль:</label>
    <input type="password" id="pass" name="pass"><br><br>

    <p>Пол:</p>
    <label for="m">Мужской</label>
    <input type="radio" id="m" name="gender" value="m">
    <label for="f">Женский</label>
    <input type="radio" id="f" name="gender" value="f"><br><br>

    <label for="hobby">Ваши хобби:</label><br>
    <input type="checkbox" id="h1" name="hobby" value="football">
    <label for="h1">Футбол</label><br>
    <input type="checkbox" id="h2" name="hobby" value="reading">
    <label for="h2">Чтение</label><br><br>

    <label for="country">Страна:</label>
    <select id="country" name="country">
        <option value="ru">Россия</option>
        <option value="by">Беларусь</option>
    </select><br><br>

    <label for="comment">Комментарий:</label><br>
    <textarea id="comment" name="comment" rows="4"></textarea><br><br>

    <input type="submit" value="Отправить">
    <input type="reset" value="Очистить">
</form>
```

### 8.7. Обязательные поля и проверка (валидация)

HTML5 умеет проверять данные прямо в браузере без программирования:

- `required` — поле обязательно к заполнению.
- `minlength` / `maxlength` — минимальная/максимальная длина.
- `min` / `max` — диапазон для чисел.
- `pattern` — проверка по регулярному выражению.

```html
<input type="email" required placeholder="Ваш e-mail">
<input type="number" min="1" max="10" step="1">
<input type="password" minlength="6" required>
```

---

### ⚠️ Разбор частых ошибок

1. **Забыли `name`.** Без `name` данные поля не будут отправлены на сервер. `name` объединяет поле в пару «имя=значение».
2. **Радиокнопки не переключаются.** Чтобы из группы можно было выбрать только одну, у всех радиокнопок группы должно быть **одинаковое** значение `name`. Если `name` разные — вы сможете отметить несколько, что неверно.
3. **Кнопка не делает ничего.** `<input type="button">` — это пустая кнопка без действия. Отправляют форму `submit`, очищают — `reset`.
4. **`placeholder` вместо `label`.** Placeholder — подсказка, а не подпись. Для доступности используйте `<label>`.
5. **Забыта кодировка / русские символы превращаются в «кракозябры».** Убедитесь, что в `<head>` есть `<meta charset="UTF-8">`.

## 9. Семантическая разметка HTML5

### 9.1. Что такое семантические теги?

До HTML5 вёрстку делали из одних `<div>` — блоков без смысла. Браузеру и поисковику было непонятно, где на странице шапка, где меню, где основное содержимое.

**Семантические теги** — это теги, которые **несут смысл** и описывают роль своего содержимого. Они появились в HTML5.

### 9.2. Основные семантические теги

| Тег | Роль |
|-----|------|
| `<header>` | Шапка страницы или раздела |
| `<nav>` | Навигация (меню) |
| `<main>` | Основное содержимое страницы |
| `<section>` | Логический раздел страницы |
| `<article>` | Самостоятельная статья/запись |
| `<aside>` | Боковая колонка, дополнительная информация |
| `<footer>` | Подвал страницы |
| `<figure>` | Иллюстрация с подписью |

### 9.3. Пример семантической структуры

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Новости</title>
</head>
<body>
    <header>
        <h1>Мой сайт о технологиях</h1>
        <nav>
            <a href="#">Главная</a>
            <a href="#">Статьи</a>
            <a href="#">Контакты</a>
        </nav>
    </header>

    <main>
        <section>
            <h2>Последние новости</h2>
            <article>
                <h3>Вышла новая версия HTML</h3>
                <p>Краткий текст новости...</p>
            </article>
            <article>
                <h3>Обновление в CSS</h3>
                <p>Ещё одна новость...</p>
            </article>
        </section>

        <section>
            <h2>Популярные статьи</h2>
            <p>Список самых читаемых материалов.</p>
        </section>
    </main>

    <aside>
        <h2>Реклама</h2>
        <p>Здесь может быть баннер.</p>
    </aside>

    <footer>
        <p>© 2026, Мой сайт. Все права защищены.</p>
    </footer>
</body>
</html>
```

### 9.4. `article` или `section`?

- `<article>` — **самостоятельный** контент, который можно вынести на отдельную страницу (статья, пост, новость).
- `<section>` — **раздел** страницы, логическая группировка (может содержать несколько `<article>`).

Простое правило: если содержимое имеет смысл само по себе (его можно прочитать отдельно) — это `<article>`. Если это просто часть логики страницы — `<section>`.

### 9.5. Зачем вообще нужна семантика?

1. **Поисковая оптимизация (SEO).** Поисковики лучше понимают структуру страницы и ранжируют её выше.
2. **Доступность.** Программы чтения с экрана лучше озвучивают страницу.
3. **Читаемость кода.** Разработчику сразу понятно назначение блоков.
4. **Будущее.** Страницы, размеченные семантически, легче поддерживать.

---

### ⚠️ Разбор частых ошибок

1. **Один `<h1>` на несколько разделов.** На странице должен быть один `<h1>` (обычно в `<header>` или сразу после него).
2. **`<header>` внутри `<footer>` и наоборот.** Не путайте: `<header>` — вверху, `<footer>` — внизу.
3. **Несколько `<main>`.** `<main>` должен быть один. Он уже подразумевает «основное», его не оборачивают в `div`.
4. **Семантика вместо стилей.** Семантические теги — это НЕ стили. `<header>` не делает текст крупнее. За вид отвечает CSS.

## 10. Мультимедиа: audio и video

HTML5 позволяет вставлять аудио и видео без внешних плагинов.

### 10.1. Аудио `<audio>`

```html
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Ваш браузер не поддерживает аудио.
</audio>
```

Текст между тегами показывается, если браузер `audio` не поддерживает.

**Атрибуты `audio`:**

- `controls` — показать панель управления (play, pause, громкость).
- `autoplay` — начать воспроизведение автоматически.
- `loop` — повторять в цикле.
- `muted` — выключить звук по умолчанию.

### 10.2. Видео `<video>`

```html
<video controls width="640" height="360" poster="preview.jpg">
    <source src="movie.mp4" type="video/mp4">
    Ваш браузер не поддерживает видео.
</video>
```

**Атрибуты `video`:**

- `controls` — панель управления.
- `poster` — картинка-заставка до начала воспроизведения.
- `width` / `height` — размер.
- `autoplay`, `loop`, `muted` — аналогично аудио.

> ℹ️ Форматы: аудио обычно `.mp3`, `.ogg`, `.wav`; видео — `.mp4`, `.webm`, `.ogg`. Разные браузеры поддерживают разные форматы, поэтому часто указывают несколько `<source>`.

---

### ⚠️ Разбор частых ошибок

1. **`autoplay` не работает.** Многие браузеры блокируют автовоспроизведение без `muted`. Если нужно автостарт — добавьте `muted autoplay`.
2. **Видео не играет.** Часто проблема в формате файла или в отсутствии `controls` — без него просто нет кнопки «Play». 
3. **Забыли закрыть пару `source`.** `<source>` — одиночный тег, скобки `/>` (в HTML5) не обязательны, но текст-основной внутри `video/audio` нужен для браузеров без поддержки.

## 11. Мета-теги и SEO

`<meta>` — одиночные теги в `<head>`, описывающие свойства страницы.

### 11.1. Основные мета-теги

```html
<html lang="ru">
<head>
    <!-- Кодировка (обязательно!) -->
    <meta charset="UTF-8">

    <!-- Описание страницы для поисковиков -->
    <meta name="description" content="Краткое описание страницы">

    <!-- Ключевые слова (сейчас почти не влияют на ранжирование) -->
    <meta name="keywords" content="html, css, уроки">

    <!-- Автор -->
    <meta name="author" content="Иван Иванов">

    <!-- Настройка области просмотра на мобильных -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Главная — Мой сайт</title>
</head>
```

### 11.2. `viewport` — почему это важно

Без `<meta name="viewport">` на мобильном телефоне страница отображается в уменьшенном виде «всё в кучу». С этим тегом страница масштабируется под ширину экрана устройства.

```
width=device-width  — ширина страницы = ширина экрана устройства
initial-scale=1.0   — начальный масштаб 100%
```

### 11.3. Open Graph (для соцсетей)

Теги Open Graph задают, как страница отображается при пересылке в соцсети и мессенджеры.

```html
<meta property="og:title" content="Заголовок страницы">
<meta property="og:description" content="Описание">
<meta property="og:image" content="https://example.com/img/preview.png">
```

---

### ⚠️ Разбор частых ошибок

1. **Отсутствует `charset`.** Без него русские буквы превращаются в «кракозябры». Ставьте `<meta charset="UTF-8">` всегда.
2. **`title` в `<body>`.** `<title>` живёт только в `<head>`, иначе не сработает.
3. **`description` слишком длинный.** Поисковик обрежет его. Держите в пределах 150–160 символов.
4. **Забыли `viewport`.** Без него мобильная версия выглядит плохо.

## 12. Практика: разбор типичных ошибок

Закрепим самое важное. Вот **сознательно сломанный** код. Найдите все ошибки, а потом сравните с правильным вариантом.

### Сломанный код:

```html
<html>
<HEAD>
<title>Ошибки
</head>
<body>
<h1>Моя страница<h2>Подзаголовок</h2>
<p>Текст с
переносом строки
<p>Новый абзац
<img src="photo.png">
<a href="ya.ru">Ссылка
<ul>
    текст списка без li
</ul>
</body>
</html>
```

### Какие здесь ошибки?

| Ошибка | Правильно |
|--------|-----------|
| Нет `<!DOCTYPE html>` | Добавить первой строкой |
| Нет `lang` у `<html>` | `<html lang="ru">` |
| `<HEAD>` (заглавные) — допустимо, но некрасиво | `<head>` |
| Не закрыт `<title>` | `</title>` закрыть |
| Забыт `<meta charset="UTF-8">` | добавить в head |
| `<h2>` открыт внутри `<h1>` | закрыть `<h1>` перед `<h2>` |
| `<p>` не закрыт и вложен <p> в <p> | закрывать каждый `<p>` |
| Перенос строки Enter'ом | использовать `<br>` или новый абзац |
| Не указан `alt` у картинки | `alt="..."` |
| `<a href="ya.ru">` — без `https://` | `https://ya.ru` |
| Ссылка не закрыта | `</a>` |
| Текст в `<ul>` без `<li>` | обернуть в `<li>` |

### Правильный код:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
</head>
<body>
    <h1>Моя страница</h1>
    <h2>Подзаголовок</h2>
    <p>Текст с<br>переносом строки</p>
    <p>Новый абзац</p>
    <img src="photo.png" alt="Моя фотография">
    <p><a href="https://ya.ru">Ссылка</a></p>
    <ul>
        <li>первый пункт</li>
        <li>второй пункт</li>
    </ul>
</body>
</html>
```
