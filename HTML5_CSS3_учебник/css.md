## 1. Введение в CSS

### 1.1. Что такое CSS?

**CSS** (Cascading Style Sheets — «каскадные таблицы стилей») — язык, который управляет **внешним видом** HTML-страницы: цветами, шрифтами, отступами, расположением элементов.

Если HTML — это «скелет» и «стены» дома, то CSS — «краска, обои и расстановка мебели».

> **Главные принципы CSS** (запомните название «каскадные»):
> 1. **Каскад** — несколько правил могут применяться к одному элементу, и они наследуются/переопределяются.
> 2. **Стили** отделены от структуры (HTML).
> 3. **Браузер сам** рассчитывает итоговый вид, складывая всё применённые правила.

### 1.2. Синтаксис CSS-правила

CSS-правило состоит из **селектора** (к кому применять) и **блока объявлений** (какие свойства задать):

```css
селектор {
    свойство: значение;
    свойство2: значение2;
}
```

Разбор примера:

```css
p {
    color: red;
    font-size: 18px;
}
```

- `p` — селектор: правило применится ко всем элементам `<p>`.
- `color: red;` — объявление: сделать текст красным.
- `font-size: 18px;` — объявление: размер шрифта 18 пикселей.

Важные мелочи:
- После **каждого** объявления ставится точка с запятой `;`.
- Свойство и значение разделяются **двоеточием** `:`.

## 2. Способы подключения CSS

Существует **три** способа подключить стили.

### 2.1. Внешний файл (рекомендуемый)

Выносим стили в отдельный файл `style.css` и подключаем его в `<head>` через `<link>`:

```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

В файле `style.css`:

```css
h1 {
    color: blue;
}
```

**Почему так лучше всего:**
- HTML и CSS разделены — код чище.
- Один файл стилей можно подключить к многим страницам.
- Браузер кэширует файл — страницы грузятся быстрее.

### 2.2. Внутренние стили (internal)

Стили пишутся прямо в `<head>` внутри тега `<style>`:

```html
<head>
    <style>
        h1 { color: blue; }
    </style>
</head>
```

Годится для одной страницы, но при разрастании `<head>` становится грязным.

### 2.3. Инлайновые (inline) стили

Стиль задаётся прямо в HTML-атрибуте элемента:

```html
<h1 style="color: blue;">Заголовок</h1>
```

**Минусы:**
- Смешивает HTML и CSS.
- Сложно поддерживать.
- Нельзя переиспользовать.

> ⚠️ **Важно:** инлайновые стили имеют **наивысший приоритет** (кроме обходимых `!important`) и «перебивают» другие. Поэтому их избегают в серьёзных проектах.

### 2.4. Приоритет (специфичность) стилей

Если одному элементу заданы стили из разных мест — побеждает тот, у кого выше **приоритет** (специфичность):

1. **Инлайновый стиль** — самый сильный.
2. **Селектор по ID**.
3. **Селектор по классу/атрибуту**.
4. **Селектор по тегу**.
5. **Наследование** от родителя — самый слабый.

```html
<style>
    #red { color: red; }     /* ID — сильнее */
    .green { color: green; } /* класс */
    p { color: black; }      /* по тегу — слабее всего */
</style>
<p id="red" class="green">Какого цвета будет текст?</p>
```

Ответ: **красный**, так как ID сильнее класса и тега.

А `!important` в конце объявления перебивает вообще всё:

```css
p { color: blue !important; }
```

Но пользуйтесь `!important` осторожно — он ломает логику каскада.

## 3. Селекторы

Селектор — «адрес», по которому браузер находит элементы для стилизации.

### 3.1. По тегу

```css
p { color: gray; }
h1 { font-size: 30px; }
```

Применяется ко **всем** элементам этого тега.

### 3.2. По классу

Класс задаётся в HTML атрибутом `class` (можно несколько классов через пробел):

```html
<p class="important">Важный текст</p>
<p>Обычный текст</p>
```

В CSS класс пишется с точкой:

```css
.important {
    font-weight: bold;
    color: red;
}
```

Стилизуются только элементы с этим классом.

Один элемент может иметь несколько классов:

```html
<p class="important red-bg">Текст с двумя классами</p>
```

```css
.important { font-weight: bold; }
.red-bg { background: #fdd; }
```

### 3.3. По ID

ID — уникальный идентификатор. На странице **только один** элемент с конкретным ID.

```html
<p id="main-text">Уникальный элемент</p>
```

В CSS ID пишется с решёткой:

```css
#main-text {
    font-size: 24px;
}
```

> ⚠️ **Частая ошибка новичка:** использовать ID там, где нужен класс, или допускать несколько элементов с одинаковым ID. ID должен быть один-единственный на странице. Для групп элементов используйте класс.

### 3.4. Универсальный селектор `*`

```css
* {
    margin: 0;
    padding: 0;
}
```

Применяется ко **всем** элементам. Часто используют для «сброса» отступов.

### 3.5. Комбинированные селекторы

- **Дочерний (прямой)** `>` — только прямые потомки:

```css
div > p { color: green; }
```
Применится к `<p>`, который является **непосредственным** ребёнком `<div>` (не к вложенным глубже).

- **Потомок (любой)** — пробел:

```css
div p { color: green; }
```
Применится ко **всем** `<p>` внутри `<div>`, на любой глубине.

- **Соседний** `+` — следующий после элемента:

```css
h1 + p { color: blue; }
```
Применится к `<p>`, который идёт **сразу** после `<h1>`.

- **Группировка** через запятую:

```css
h1, h2, h3 { color: darkblue; }
```

### 3.6. Псевдоклассы (состояния)

Описывают **состояние** элемента, часто — при взаимодействии:

- `:hover` — при наведении мыши.
- `:active` — в момент клика.
- `:focus` — при получении фокуса (например, поле ввода).
- `:first-child` — первый ребёнок родителя.
- `:last-child` — последний ребёнок.
- `:nth-child(2)` — n-ый ребёнок.

```css
a {
    color: blue;
}
a:hover {
    color: red;
    text-decoration: underline;
}
a:visited {
    color: purple;
}
```

### 3.7. Псевдоэлементы

Создают «виртуальные» элементы. Пишутся с двумя двоеточиями `::`.

- `::before` — перед содержимым.
- `::after` — после содержимого.
- `::first-line` — первая строка.
- `::selection` — выделенный текст.

```css
p::first-letter {
    font-size: 200%;
    font-weight: bold;
    color: red;
}
```

---

### ⚠️ Разбор частых ошибок

1. **Точка перед классом везде.** В HTML класс — просто `class="name"`, без точки. Точка ставится **только в CSS** перед именем.
2. **Решётка для ID только в CSS.** В HTML ID указывается без `#`.
3. **Пробел вместо `>`.** `div p` и `div > p` — разные вещи. Пробел = любой потомок, `>` = прямой.
4. **Забыли `:hover`** — часто пишут просто `hover`. Двоеточие обязательно.
5. **Смешивают `::` и `:`.** Псевдоклассы (по сути состояния) — `:hover`. Псевдоэлементы — `::after`. Хотя браузеры терпимы, современный стандарт — два двоеточия у псевдоэлементов.

## 4. Цвета и фон

### 4.1. Способы задания цвета

К свойству `color` (цвет текста) применимы разные форматы:

**1. Именованные цвета:**

```css
p { color: red; }
h1 { color: blue; }
```

Словом можно задать множество цветов: `red`, `green`, `blue`, `black`, `white`, `gray`, `orange`, `purple` и др.

**2. HEX-код (шестнадцатеричный):**

```css
p { color: #ff0000; } /* красный */
p { color: #00ff00; } /* зелёный */
p { color: #0000ff; } /* синий */
p { color: #333333; } /* тёмно-серый */
```

Формат `#RRGGBB`, где RR, GG, BB — красная/зелёная/синяя составляющая от `00` до `ff`.
Короткая форма `#rgb` — когда пары одинаковые (например, `#f00` = `#ff0000`).

**3. RGB / RGBA (с прозрачностью):**

```css
p { color: rgb(255, 0, 0); }        /* красный */
p { color: rgba(255, 0, 0, 0.5); } /* красный, 50% прозрачности */
```

Числа от 0 до 255. Прозрачность `alpha` — от 0 (полностью прозрачный) до 1 (непрозрачный).

**4. HSL / HSLA (оттенок, насыщенность, светлота):**

```css
p { color: hsl(0, 100%, 50%); }      /* красный */
p { color: hsla(0, 100%, 50%, 0.6); }
```

Понятнее управлять оттенком: `hue` — угол цветового круга от 0 до 360.

### 4.2. Цвет фона `background-color`

```css
div {
    background-color: #f0f0f0;
}
```

### 4.3. Фоновое изображение `background-image`

```css
div {
    background-image: url("pattern.png");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}
```

- `background-repeat` — повторение: `repeat` (по умолч.), `no-repeat`, `repeat-x`, `repeat-y`.
- `background-position` — позиция: `center`, `top`, `left`, `right`, `bottom` или координаты.
- `background-size` — размер: `cover` (заполнить весь блок, обрезав края), `contain` (вписать целиком), или конкретные размеры.

### 4.4. Сокращённое свойство `background`

```css
div {
    background: url("bg.png") no-repeat center/cover #fff;
}
```

Порядок: `background: color image repeat position/size`.

---

### ⚠️ Разбор частых ошибок

1. **Опечатки в HEX.** `#ff0000` — 6 символов. Запись `#ff00` — ошибка.
2. **Путь к картинке в `url()`.** Проверяйте, что файл существует и путь верный. `url("img.png")` — без лишних пробелов.
3. **`background` перетёрло другие свойства.** Сокращённое `background:` сбрасывает незаданные значения. Разделите свойства, если нужен контроль.

## 5. Типографика: работа с текстом

### 5.1. Шрифт `font-family`

Задаёт набор шрифтов. Браузер использует первый из доступных.

```css
body {
    font-family: Arial, Helvetica, sans-serif;
}
```

- Если `Arial` нет — возьмёт `Helvetica`, потом любая без засечек.
- `serif` — шрифты с засечками (Times).
- `sans-serif` — без засечек (Arial, Verdana).
- `monospace` — моноширинные (Courier).

Хорошая практика — в конце ставить **семейство-запас** (`sans-serif`).

### 5.2. Размер шрифта `font-size`

```css
p { font-size: 16px; }
```

Единицы размера:
- `px` — пиксели (фиксированные).
- `em` — относительно родительского размера шрифта (1em = размер родителя).
- `rem` — относительно размера шрифта **корня** (`<html>`), удобнее для адаптива.
- `%` — процент от родителя.

Пример:

```css
html { font-size: 16px; }        /* базовый */
h1 { font-size: 2rem; }           /* 32px */
p  { font-size: 1rem; }           /* 16px */
span { font-size: 1.5em; }        /* в 1.5 раза больше родителя */
```

### 5.3. Насыщенность `font-weight`

```css
p { font-weight: bold; }   /* или numeric: 100..900 */
```

Значения: `normal` (400), `bold` (700), либо числа от 100 до 900 с шагом 100.

### 5.4. Стиль и декорация

```css
em { font-style: italic; }        /* курсив */
u { text-decoration: underline; } /* подчёркивание */
del { text-decoration: line-through; } /* зачёркивание */
a { text-decoration: none; }      /* убрать подчёркивание у ссылок */
```

### 5.5. Выравнивание `text-align`

```css
p { text-align: left; }   /* по левому краю (по умолч.) */
p { text-align: center; } /* по центру */
p { text-align: right; }  /* по правому */
p { text-align: justify; } /* по ширине (выравнивает оба края) */
```

### 5.6. Межстрочный интервал `line-height`

```css
p {
    line-height: 1.5;      /* 1.5 от размера шрифта */
}
```

Удобно задавать без единиц — это число, умножаемое на размер шрифта.

### 5.7. Регистр и пробелы

```css
h1 { text-transform: uppercase; }  /* ВЕРХНИЙ РЕГИСТР */
h1 { text-transform: lowercase; }
p { text-transform: capitalize; }  /* Каждое слово с большой */
p { letter-spacing: 2px; }         /* расстояние между буквами */
p { word-spacing: 4px; }           /* между словами */
p { white-space: nowrap; }         /* запрет переносов */
```

### 5.8. Тень текста `text-shadow`

```css
h1 {
    text-shadow: 2px 2px 4px rgba(0,0,0,0.5);
}
```

Формат: `сдвиг_по_X сдвиг_по_Y размытие цвет`.

---

### ⚠️ Разбор частых ошибок

1. **Забыли запасное семейство.** `font-family: Arial` — если у пользователя нет Arial, будет системный. Пишите `Arial, sans-serif`.
2. **Лишний `;` в конце значения.** Не `color: red;;`, а один разделитель на объявление.
3. **`text-align` не центрирует блок.** `text-align: center` центрирует **текст**, а не сам блок. Для центрирования блока — `margin: 0 auto`.
4. **`line-height` с `px` при адаптиве** — лучше безразмерное значение, чтобы масштабировался вместе со шрифтом.

## 6. Блочная модель

**Блочная модель (box model)** — как браузер считает размер элемента. Это фундамент вёрстки.

### 6.1. Состав блочной модели

Каждый элемент — «коробка» из четырёх слоёв (правило «изнутри наружу»):

1. **`content`** — само содержимое (текст, картинка).
2. **`padding`** — внутренний отступ (от краёв содержимого до границы).
3. **`border`** — граница (рамка).
4. **`margin`** — внешний отступ (от границы до других элементов).

```
┌────────────────────────────────┬──────────┐
│            margin              │          │
│  ┌──────────────────────────┐  │          │
│  │         border           │  │          │
│  │  ┌────────────────────┐  │  │          │
│  │  │      padding       │  │  │          │
│  │  │  ┌──────────────┐  │  │  │          │
│  │  │  │  content     │  │  │  │          │
│  │  │  └──────────────┘  │  │  │          │
│  │  └────────────────────┘  │  │          │
│  └──────────────────────────┘  │          │
└────────────────────────────────┴──────────┘
```

### 6.2. `padding` — внутренний отступ

```css
.box {
    padding: 10px;            /* со всех сторон 10px */
    padding: 5px 10px;        /* сверху/снизу 5px, слева/справа 10px */
    padding: 5px 10px 15px 20px; /* сверху, справа, снизу, слева (по часовой) */
}
```

Также по отдельности: `padding-top`, `padding-right`, `padding-bottom`, `padding-left`.

### 6.3. `margin` — внешний отступ

Работает аналогично `padding`, но снаружи:

```css
.box {
    margin: 20px;          /* со всех сторон */
    margin: 10px auto;     /* сверху/снизу 10px, слева/справа автоматически (центрирует)*/
}
```

**Центрирование блока по горизонтали:**

```css
.box {
    width: 200px;
    margin: 0 auto; /* слева и справа auto -> блок по центру */
}
```

> ⚠️ **`margin: 0 auto` центрирует только блочные элементы с заданной шириной!** На тексте или элементы с `width: auto` не сработает.

### 6.4. `border` — граница

```css
.box {
    border: 2px solid red;          /* толщина, стиль, цвет */
    border-radius: 8px;             /* скругление углов */
}
```

Стили границы: `solid` (сплошная), `dashed` (пунктир), `dotted` (точки), `double` (двойная), `none`.

Отдельно: `border-top`, `border-right` и т.д., либо `border-width`, `border-style`, `border-color`.

### 6.5. Ширина и высота `width` / `height`

```css
.box {
    width: 300px;
    height: 150px;
}
```

Значения: фиксированные (`px`), проценты (`%` от родителя), `auto`, `max-width`, `min-height` и т.д.

```css
.box {
    max-width: 600px; /* не шире 600px, но может быть уже */
    min-height: 100px; /* не ниже 100px */
}
```

### 6.6. `box-sizing` — важнейшее свойство

Это ключ к пониманию размеров. По умолчанию (`content-box`) ширина `width` = ширина **только содержимого**, а padding и border добавляются **сверху**. Из-за этого элемент оказывается шире, чем вы задали.

```css
/* По умолчанию */
.box {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    /* Итоговая ширина = 200 + 40 + 4 = 244px !!! */
}
```

Чтобы `width` включал padding и border, ставят `box-sizing: border-box`:

```css
.box {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    box-sizing: border-box;
    /* Итоговая ширина ровно 200px */
}
```

Стандартный приём — применить `border-box` сразу ко всем элементам:

```css
*, *::before, *::after {
    box-sizing: border-box;
}
```

---

### ⚠️ Разбор частых ошибок

1. **Элемент «шире, чем хотел».** Забыт `box-sizing: border-box` — padding и border добавляются к width. Из-за этого блоки не помещаются в ряд.
2. **`margin: 0 auto` не центрирует.** Он не работает у строчных элементов и у элементов без фиксированной ширины.
3. **Схлопывание margin.** Вертикальные `margin` двух соседних блоков **не складываются**, а берётся больший из них (схлопывание). Учитывайте это при вычислении отступов.
4. **Путаница padding и margin.** `padding` — внутри блока (фон/рамка захватывают), `margin` — снаружи (между блоками, фон не захватывает).

## 7. Display и позиционирование

### 7.1. Свойство `display`

Управляет тем, **как** элемент отображается и участвует в потоке.

| Значение | Поведение |
|----------|-----------|
| `block` | Блочный: на всю ширину, новая строка |
| `inline` | Строчный: в строке, ширина по содержимому |
| `inline-block` | Как строчный, но можно задавать width/height |
| `none` | Полностью скрыть (элемент не занимает места) |
| `flex` | Гибкий контейнер (раздел 8) |
| `grid` | Сетка |

```css
.hidden { display: none; }     /* элемент исчезнет полностью */
.inbl { display: inline-block; }
```

> **`display: none` против `visibility: hidden`:** первый убирает элемент из потока (место освобождается), второй — просто делает невидимым, но элемент **занимает место**.

### 7.2. Позиционирование `position`

Определяет способ расположения элемента относительно других.

| Значение | Поведение |
|----------|-----------|
| `static` | По умолчанию, элемент в потоке. Offsets не работают |
| `relative` | Сдвиг относительно своего обычного места (смещается, но место за ним сохраняется) |
| `absolute` | Позиционируется относительно ближайшего позиционированного предка; выпадает из потока |
| `fixed` | Прибит к окну браузера, не двигается при прокрутке |
| `sticky` | Липкий: ведёт себя как relative, но «прилипает» при прокрутке до границы |

У позиционированных элементов (не `static`) работают свойства `top`, `right`, `bottom`, `left` и `z-index`.

**`relative`:**

```css
.box {
    position: relative;
    top: 20px;  /* сдвинется вниз на 20px от обычного места */
    left: 10px;
}
```

**`absolute`** (чаще всего «относительно`relative`-родителя»):

```html
<div class="parent">
    <div class="child">Плашка</div>
</div>
```

```css
.parent {
    position: relative; /* точка отсчёта для child */
}
.child {
    position: absolute;
    top: 0;
    right: 0; /* прижмём в правый верхний угол родителя */
}
```

Если родитель не позиционирован, `absolute` считается от всего окна/ближайшего позиционированного предка.

**`fixed`:**

```css
.menu {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}
```
Меню останется наверху при прокрутке.

**`sticky`:**

```css
.header {
    position: sticky;
    top: 0; /* прилипнет к верху при прокрутке */
}
```

### 7.3. `z-index` — кто поверх

При наложение позиционированных элементов верхним оказывается тот, у кого **больше** `z-index`:

```css
.a { position: absolute; z-index: 1; }
.b { position: absolute; z-index: 2; } /* поверх a */
```

`z-index` работает только у **позиционированных** элементов (не `static`).

---

### ⚠️ Разбор частых ошибок

1. **`top`/`left` не работают.** Убедитесь, что установлено `position` (не `static`).
2. **`absolute` «улетает».** Если родитель не `relative`, элемент позиционируется от всего окна. Ставьте родителю `position: relative`.
3. **`z-index` не срабатывает.** Он не работает на элементах с `position: static`. Добавьте `position` (relative/absolute/fixed).
4. **`display: none` оставлен для «плавного скрытия».** `none` — резкое исчезновение без анимации. Для плавности — opacity/transition.

## 8. Flexbox: гибкая раскладка

Flexbox — современный способ **раскладывать элементы в ряд/колонку** и выравнивать их. Он устраняет боль сложной вёрстки на float/inline-block.

### 8.1. Как включить

Родителю (контейнеру) задаём `display: flex`:

```html
<div class="row">
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
</div>
```

```css
.row {
    display: flex;
}
```

Теперь все `item` встанут **в одну строку** (выстроились по горизонтали).

### 8.2. Оси и направления

- **Главная ось** — направление расположения элементов (по умолчанию горизонталь).
- **Поперечная ось** — перпендикулярна главной.

`flex-direction` меняет направление главной оси:

```css
.row { display: flex; flex-direction: row; }            /* горизонталь (по умолч.) */
.row { display: flex; flex-direction: row-reverse; }    /* горизонталь, справа налево */
.row { display: flex; flex-direction: column; }         /* вертикаль, сверху вниз */
.row { display: flex; flex-direction: column-reverse; } /* вертикаль, снизу вверх */
```

### 8.3. Перенос `flex-wrap`

По умолчанию элементы стараются влезть в одну строку. Чтобы переносить:

```css
.row {
    display: flex;
    flex-wrap: wrap; /* перенос на новую строку */
}
```

### 8.4. Выравнивание по главной оси `justify-content`

```css
.row {
    display: flex;
    justify-content: center;    /* по центру */
    justify-content: space-between; /* по краям, равное расстояние между */
    justify-content: space-around;  /* равные отступы вокруг */
    justify-content: space-evenly;  /* одинаковое расстояние везде */
    justify-content: flex-start;    /* начало (по умолч.) */
    justify-content: flex-end;      /* конец */
}
```

### 8.5. Выравнивание по поперечной оси `align-items`

```css
.row {
    display: flex;
    align-items: center;       /* по центру поперёк */
    align-items: flex-start;   /* начало */
    align-items: flex-end;     /* конец */
    align-items: stretch;      /* растянуть (по умолч.) */
}
```

### 8.6. Размеры элементов `flex`

Свойства `flex-grow`, `flex-shrink`, `flex-basis`, и сокращённое `flex`. Классика — `flex: 1`, заставляющая элементы делить пространство поровну:

```css
.item { flex: 1; } /* каждый элемент возьмёт равную долю */
```

### 8.7. Полный пример (меню + карточки)

```html
<div class="nav">
    <a href="#">Главная</a>
    <a href="#">О нас</a>
    <a href="#">Контакты</a>
</div>
<div class="cards">
    <div class="card">Карточка 1</div>
    <div class="card">Карточка 2</div>
    <div class="card">Карточка 3</div>
</div>
```

```css
.nav {
    display: flex;
    justify-content: space-around;
    background: #333;
}
.nav a {
    color: white;
    padding: 10px;
    text-decoration: none;
}
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;            /* расстояние между карточками */
}
.card {
    flex: 1 1 200px;      /* растёт, сжимается, баз. 200px */
    background: #f0f0f0;
    padding: 20px;
    border-radius: 8px;
}
```

> Свойство `gap` задаёт расстояние между элементами flex-контейнера (и поддерживается в grid тоже).

### 8.8. Как центрировать всё

Три строки для идеального центрирования:

```css
.parent {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

---

### ⚠️ Разбор частых ошибок

1. **Flex не работает у детей.** `display: flex` ставится на **родителя**. Свойства `justify-content` и `align-items` — тоже на родителя, а не на детей.
2. **`justify-content` путают с `align-items`.** Первый — вдоль главной оси (по горизонтали, если row), второй — вдоль поперечной (вертикаль).
3. **`justify-content` не работает.** Если `flex-direction: column`, главная ось стала вертикальной, и `justify-content` теперь выравнивает **по вертикали**. При `column` используйте `align-items` для горизонтали.
4. **Забыли `gap` или считают отступы margin'ами.** `gap` проще и надёжнее для расстояний между flex-элементами.

## 9. CSS3: новые возможности

### 9.1. Скругление углов `border-radius`

```css
.box { border-radius: 10px; }        /* все углы */
.box { border-radius: 50%; }         /* круг (если квадратный блок) */
#avatar { border-radius: 50%; }      /* круглый аватар */
```

### 9.2. Тени `box-shadow`

```css
.card {
    box-shadow: 2px 4px 8px rgba(0,0,0,0.3);
}
```

Формат: `box-shadow: сдвиг_X сдвиг_Y размытие_распространение цвет`.

- `2px 4px` — сдвиг по X и Y.
- `8px` — размытие.
- можно добавить `inset` для внутренней тени.

### 9.3. Градиенты `linear-gradient` / `radial-gradient`

**Линейный (направленный) градиент:**

```css
.box {
    background: linear-gradient(to right, red, yellow);
    /* слева направо от красного к жёлтому */
}
.box2 {
    background: linear-gradient(45deg, #ff9966, #ff5e62);
}
```

**Радиальный (круговой) градиент:**

```css
.box3 {
    background: radial-gradient(circle, white, blue);
}
```

Можно несколько цветов и стопов:

```css
.box4 {
    background: linear-gradient(to bottom, red 0%, white 50%, blue 100%);
}
```

### 9.4. Переходы `transition`

Плавное изменение одного свойства при изменении (например, при hover):

```css
.btn {
    background: blue;
    transition: background 0.3s ease;
}
.btn:hover {
    background: darkblue; /* плавно изменится за 0.3s */
}
```

Синтаксис `transition: свойство длительность функция-скорости [задержка]`.

Пример — плавный «отклик» при наведении:

```css
.card {
    transition: all 0.3s ease; /* all = все свойства */
}
.card:hover {
    transform: scale(1.05);   /* увеличивается на 5% */
    box-shadow: 0 8px 16px rgba(0,0,0,0.3);
}
```

### 9.5. Трансформации `transform`

Изменяют геометрию элемента (не двигая его из потока):

```css
.box { transform: rotate(45deg); }        /* поворот */
.box { transform: scale(1.5); }           /* масштаб */
.box { transform: translate(20px, 10px); }/* сдвиг по X, Y */
.box { transform: skew(10deg); }          /* наклон */
```

Можно комбинировать: `transform: translate(-50%,-50%) rotate(10deg);`

### 9.6. Анимация `@keyframes` и `animation`

Позволяет создавать собственную анимацию.

```css
@keyframes bounce {
    0%   { transform: translateY(0); }
    50%  { transform: translateY(-20px); }
    100% { transform: translateY(0); }
}

.ball {
    animation: bounce 1s infinite;
}
```

Разбор: `animation: имя длительность [повторение] [и др.]`.
- `infinite` — бесконечное повторение.
- `alternate` — туда-обратно.

Полный набор:

```css
.ball {
    animation-name: bounce;
    animation-duration: 1s;
    animation-iteration-count: infinite;
    animation-timing-function: ease;
}
```

### 9.7. `opacity` — прозрачность

```css
.half { opacity: 0.5; } /* полупрозрачный */
```

В отличие от `rgba` на фоне, `opacity` делает прозрачным весь элемент (включая текст).

---

### ⚠️ Разбор частых ошибок

1. **`transform` и `transition` перепутаны.** `transform` — изменение геометрии (само преобразование), `transition` — плавность изменения между состояниями. Для плавного hover нужны обе: свойство `transition` + изменение `transform` в `:hover`.
2. **Синтаксис градиента.** Не забудьте `linear-gradient(...)`. Начинающие пишут `gradient(...)` — это неверно.
3. **`box-shadow`/`text-shadow` без запятых между частями:** сдвиг и размытие разделяются **пробелом**, а не запятой. `2px, 4px, 8px` — ошибка.
4. **`transition: all` тормозит.** На больших станицах анимировать всё `all` дорого. Лучше перечислять конкретные свойства.
5. **Воспроизведение анимации на 0%. В `@keyframes` одно состояние — анимации нет.**

## 10. Адаптивность и медиа-запросы

### 10.1. Зачем нужна адаптивность

Сайты открываются на телефонах, планшетах и компьютерах с разной шириной экрана. Адаптивность — способ заставить макет «перестраиваться» под размер экрана.

### 10.2. Основа — правильный `viewport`

Убедитесь, что в `<head>` есть:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Без него мобильная вёрстка выглядит «сжатой».

### 10.3. Медиа-запросы `@media`

Позволяют применить CSS только при выполнении условия (например, ширины экрана).

```css
/* Базовые стили (для всех) */
.cards {
    display: flex;
    flex-direction: row;
    gap: 20px;
}

/* Когда ширина окна <= 600px (мобильные) */
@media (max-width: 600px) {
    .cards {
        flex-direction: column; /* карточки станут в столбик */
    }
    .nav a {
        display: block;         /* меню перестроится в столбик */
    }
}
```

### 10.4. Логика max-width vs min-width

- **`max-width`** — стили применяются, когда экран **меньше или равен** указанной ширине («для маленьких»). Строите от большого к маленькому.
- **`min-width`** — стили, когда экран **больше или равен** указанной ширине («для больших»). Строите от маленького к большому.

```css
/* десктоп */
body { font-size: 18px; }

/* планшет */
@media (max-width: 900px) {
    body { font-size: 16px; }
}

/* мобильный */
@media (max-width: 600px) {
    body { font-size: 14px; }
}
```

### 10.5. Типичные «брейкпоинты»

Часто используют: 576px (моб.), 768px (планшет), 992px (десктоп), 1200px (большой).

### 10.6. Гибкие единицы

Для адаптивности удобны:
- `%` — проценты ширины.
- `vw` / `vh` — процент от ширины/высоты окна.
- `rem` — относительно базового размера шрифта.

```css
.container {
    width: 90%;
    max-width: 1200px;
    margin: 0 auto;
}
```

Картинки делают «резиновыми»:

```css
img {
    max-width: 100%;
    height: auto;
}
```

---

### ⚠️ Разбор частых ошибок

1. **Забыли `viewport`.** Самый частый «косяк» — мобильная версия не работает.
2. **Фиксированная ширина в `px` у всего.** Блоки не сжимаются. Используйте `%`, `max-width`, `vw`.
3. **Нет брейкпоинта для мобильных.** Если `@media` нет — на телефоне всё будет мелким и узким.
4. **Путают `min-width` и `max-width`.** Перечитайте пункт 10.4 и проверьте логику своих запросов.
5. **Медиа-запрос перебили другие стили.** Из-за специфичности media-правила могут не срабатывать. Убедитесь в приоритетах.

## 11. Практика: разбор типичных ошибок

Приведём **сломанный** CSS и найдём в нём проблемы.

### Сломанный CSS:

```css
/* 1 */
.box { width: 200px; pading 10px; }
/* 2 */
.my-class { color red; }
/* 3 */
#myId .p { color: blue; }
/* 4 */
.center { margin: auto; }
/* 5 */
a:hover transform: scale(1.1);
/* 6 */
div {
    background: url("img.png");
    background repeat: no-repeat;
}
```

### Разбор ошибок:

| № | Ошибка | Правильно |
|---|--------|-----------|
| 1 | `pading` — опечатка | `padding: 10px;` |
| 1 | Нет `:` после `10px` | `padding: 10px;` |
| 2 | Нет `:` между `color` и `red` | `color: red;` |
| 3 | `.p` внутри `#myId` — нет элемента `.p` в `#myId`; вероятно, хотели `p` | `#myId p` |
| 4 | `margin: auto` (без 0/auto) центрирует плохо — надо оба `auto` | `margin: 0 auto;` (плюс width) |
| 5 | `transform` в hover без `transition` — резкий скачок; вдобавок нет `:` в объявлении и `;` | `a { transition: transform 0.3s; } a:hover { transform: scale(1.1); }` |
| 5 | Нет `:` и `;` — синтаксис сломан | исправить структуру |
| 6 | `background repeat` — пробел вместо дефиса | `background-repeat: no-repeat;` |

### Правильный CSS:

```css
.box {
    width: 200px;
    padding: 10px;
}

.my-class {
    color: red;
}

#myId p {
    color: blue;
}

.center {
    width: 200px;
    margin: 0 auto;
}

a {
    transition: transform 0.3s;
}
a:hover {
    transform: scale(1.1);
}

div {
    background: url("img.png") no-repeat;
}
```
